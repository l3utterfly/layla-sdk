# Image Lab for Layla

Reference sheets, image edits and checkpoint inspection.

Generate with installed Layla image models, arrange up to eight image references as a contact sheet, edit a source image, and inspect safetensors architecture metadata locally.

## Files

- `index.html` — the prebuilt, single-file mini-app.
- `app.json` — mini-app metadata (title, tagline, description, icon, background).
- `icon.png`, `bg.png` — icon and background image referenced by `app.json`.

## Install

Zip the contents of this folder (with `app.json` and `index.html` at the root of the zip, no parent folder) and import it into Layla as a mini-app.
